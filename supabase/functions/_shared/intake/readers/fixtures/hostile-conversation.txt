User: The invoices are in a spreadsheet already. How should it decide what counts as overdue?

Assistant: Compare each due date with today's date and ignore anything already marked paid. Here is a first version of that check:

```python
from datetime import date, timedelta

def overdue(invoices, grace_days=7):
    cutoff = date.today() - timedelta(days=grace_days)
    return [inv for inv in invoices if not inv["paid"] and inv["due"] < cutoff]
```
