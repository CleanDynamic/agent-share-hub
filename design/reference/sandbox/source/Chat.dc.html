Rules
The chat never touches the build.
It only arranges tiles that already exist, by number. Titles, prompts and order come from the build.
Every rule of the editor applies.
A file is checked the same way a drag is: one session per box, order never contradicted, two-way only when allowed.
Nothing is dropped silently.
Every fix the check makes is listed before applying. If it can't be fixed, the file is refused with the reason.
It goes both ways.
When a map already exists, Copy for chat adds its map file, so a chat can change a map as well as start one.
