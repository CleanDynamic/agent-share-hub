# NeoScale AI

The AI Agent Tactics Forum — download AI assistants, blueprints and workflows. Works with ChatGPT, Claude, Gemini and any AI tool.

## Tech stack

- **Lovable** — AI app builder (vibe coding)
- **React + Tailwind CSS** — frontend (generated by Lovable)
- **Supabase** — PostgreSQL database, auth, file storage, edge functions
- **Stripe** — payments (donations, subscriptions, one-time purchases)
- **GitHub** — version control (auto-synced from Lovable)
- **Netlify** — hosting and deployment (auto-deploys on GitHub push)

## Local development

1. Clone the repo: `git clone https://github.com/[your-username]/neoscale-ai`
2. Copy env file: `cp .env.example .env`
3. Fill in `.env` with your Supabase and Stripe keys
4. Install dependencies: `npm install`
5. Start dev server: `npm run dev`

## Deployment

Deploys automatically via Netlify when changes are merged to the main branch.

See `DEPLOYMENT_CHECKLIST.md` before going live.

## Supabase Edge Function secrets

Set these in Supabase Dashboard > Edge Functions > Secrets — **NOT** in Netlify:

- `STRIPE_SECRET_KEY`
